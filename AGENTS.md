# Repository Guidelines

## Project Structure & Module Organization

The Cloudflare Worker application lives in `src/`. `src/index.ts` is the entry point,
`src/app.ts` applies Cloudflare Access authentication, exposes the Litestream dashboard at
`/_litestream`, and proxies other requests to the singleton `Grafana` Durable Object.
`src/grafana.ts` owns the Grafana container, container lifecycle hooks, outbound host routing,
WebSocket fallback behavior, and metrics scraping/export.

Reusable Worker code lives in `src/lib/`:

- `auth.ts` converts the Cloudflare Access identity into the JWT consumed by Grafana.
- `ltx-webdav.ts` implements Litestream's WebDAV storage. Levels 0 and 1 use Durable Object SQL
  (with large bodies spilled to R2); higher levels use R2 directly.
- `litestream.tsx` wraps the Litestream socket RPC and renders its diagnostic pages.
- `ai.ts`, `grpc.ts`, and `metric.ts` implement the Grafana LLM endpoint and telemetry adapters.
- `test-do.ts` and `index.stub.ts` provide the Durable Object entry point used by Worker tests.

Container assets are under `grafana/`. `grafana/Dockerfile` builds the Grafana/Litestream image,
installs plugins, and compiles `grafana/webdav-proxy`, a small Go proxy that translates WebDAV
methods for container outbound requests. Grafana, Litestream, and provisioning configuration are
kept beside the Dockerfile.

Production bindings and migrations are declared in `wrangler.jsonc`; test-only bindings are in
`wrangler.test.jsonc`. `worker-configuration.d.ts` is generated by Wrangler and must not be edited
manually. `worker-configuration.test.d.ts` contains the additional test binding declaration.

## Build, Test, and Development Commands

Use Node 26 and pnpm 11 as pinned by `.node-version` and `package.json`.

- `pnpm install` installs the locked JavaScript dependencies.
- `pnpm dev` starts Wrangler locally with the `dev` environment.
- `pnpm test --run` runs the Worker Vitest suite once; `pnpm test` may enter watch mode locally.
- `pnpm lint` checks Oxfmt, Oxlint, and both TypeScript project references.
- `pnpm fix` applies supported Oxfmt and Oxlint fixes.
- `pnpm generate` regenerates production Cloudflare binding types.
- `pnpm deploy` deploys the production Worker and container configuration.
- `(cd grafana/webdav-proxy && go test ./...)` runs the Go proxy tests.

Run `pnpm lint`, `pnpm test --run`, and the Go tests before submitting changes that touch their
respective code paths.

## Coding Style & Naming Conventions

Prefer explicit types at API boundaries and named exports for reusable modules. Keep the
`X-Method` encoding contract synchronized between the Go proxy and `decodeWebDAVMethod` in
`src/lib/ltx-webdav.ts`.

## Testing Guidelines

Worker tests use Vitest with `@cloudflare/vitest-pool-workers` and `wrangler.test.jsonc`. Place tests
beside their implementation as `*.test.ts`. Exercise observable behavior such as status, headers,
body, Durable Object SQL state, and R2 side effects. Use the helpers from `cloudflare:test` for
Durable Object inspection and delete any R2 keys created by a test. Add regression coverage for
behavior changes; there is no coverage threshold.

Go tests live beside the proxy as `*_test.go`. When changing translated methods, verify both the
outgoing HTTP method and `X-Method` header, and preserve the request path, query, body, and upstream
response.

## Commit & Pull Request Guidelines

Use short imperative commit subjects, normally with Conventional Commit prefixes such as `feat:`,
`fix:`, `refactor:`, or `test:`. Keep commits focused. Pull requests should explain user-visible or
operational impact, list validation commands, and call out changes to bindings, Durable Object
migrations, container images, Grafana/Litestream configuration, or generated files. Link relevant
issues; include screenshots only for Grafana UI changes.

## Security & Configuration

Do not commit `.env*`, Wrangler secrets, credentials, private JWT keys, or production data. Use
`scripts/generate-key.js` to generate local Ed25519 key material when needed. Keep Access audience,
JWT/JWK settings, outbound host names, and Grafana's `auth.jwt` configuration aligned. Review
dependency, plugin, Grafana, Litestream, and Go toolchain updates for compatibility with the pinned
container build and Cloudflare runtime.
